Français

  • Ce deck : design visuel, UX, couleurs, typographie, multilingue, logo, technique

Desafio / Défi de design

Português

  • Confederação internacional — PT, BR, MA, FR
  • Tom institucional, discreto, diplomático
  • Texto constitucional oficial com peso visual
  • Quatro idiomas incluindo árabe RTL

Français

  • Confédération internationale — PT, BR, MA, FR
  • Ton institutionnel, discret, diplomatique
  • Texte constitutionnel officiel avec gravité visuelle
  • Quatre langues dont l'arabe RTL

Conceito / Concept — Institutionnel classique

Português

  • Metáfora do documento — moldura centrada, pergaminho
  • Hero cerimonial — navy, moldura dourada dupla
  • Ritmo de secções — claro / quente / escuro
  • Restrição — sem cantos arredondados, sem animações

Français

  • Métaphore du document — cadre centré, parchemin
  • Hero cérémoniel — navy, double cadre doré
  • Rythme des sections — clair / chaud / sombre
  • Retenue — sans coins arrondis, sans animations

Português

  • Pergaminho quente — não branco estéril
  • Dourado contido — acento, não decoração excessiva
  • Todos os tokens em :root — fácil de manter

Français

  • Parchemin chaud — pas de blanc stérile
  • Or contenu — accent, pas de décoration excessive
  • Tous les tokens dans :root — facile à maintenir

Português

  • Serif para voz institucional
  • Sans para leitura e interface
  • Sem Inter, Poppins, Playfair — evita estética startup

Français

  • Serif pour la voix institutionnelle
  • Sans pour la lecture et l'interface
  • Pas d'Inter, Poppins, Playfair — évite l'esthétique startup
